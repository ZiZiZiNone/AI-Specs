# Feature 任务

需求→设计→实现→检查。

## 流程
1. 需求：读取并确认需求，补齐缺失项。
2. 设计：判断 pattern，确定 State/Logic/Service 结构。
3. 实现：按 Pattern→State→Logic→Service→UI 落地。
4. 检查：过 self-check 清单，验证可运行。

## 规则
- 不做需求外的功能（YAGNI）。
- 信息不足先确认，不带猜测实现。
