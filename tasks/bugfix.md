# Bugfix 任务

复现→定位→修复→验证。

## 流程
1. 复现：稳定复现，确认触发条件。
2. 定位：追根因，检查所有调用方（修共享函数而非单点）。
3. 修复：最小改动修根因，不夹带重构。
4. 验证：回归验证修复场景与相关调用方。

## 规则
- 修复根因不是症状；若为权宜方案需注明。
- 不顺手改无关代码。
- 授权面：定向写（C6）。改动限于改动点清单加真实调用链上被迫改的文件、fixture 与测试；
  调用链上的改动不算外扩（见 `protocol/task-boundary.md`「定向写档的调用链例外」）。
