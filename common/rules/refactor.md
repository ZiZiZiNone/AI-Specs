# 通用重构规范

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析。见 `<SPEC_ROOT>/README.md`「路径基准」。

## 安全重构协议

1. **行为严格不变**：重构只改善内部结构（可读性、解耦、可测试性），不改变外部可观测行为（接口契约、返回值、副作用、边界错误码）。
2. **特征测试前置**：重构前先确认现有自动化测试全绿；若目标模块缺少测试，必须先补齐覆盖当前真实行为的特征测试（Characterization Test），再动手改结构。
3. **提交严格隔离（`COM-018`）**：一次重构只做一件事，避免夹带功能改动（禁止在同一 Commit 或 PR 中混杂“结构重构”与“新功能开发 / Bug 修复”），保证 Diff 可独立评审与安全回滚。
4. **小步可回滚**：大范围重构拆分为多个可独立通过测试的原子步骤；跨模块迁移采用 Strangler Fig（新实现并行就位 → 逐调用方切换 → 按 `FE-005` 彻底删除旧实现），禁止长时间半成品共存。
5. **同口径验收**：重构前后使用同一套契约测试与核心性能基线对比，确保无功能回归与明显性能退化。

## 检查清单

- [ ] 重构前已有绿灯基线测试（无测试已先补特征测试）
- [ ] 本次变更未夹带新需求或行为改动
- [ ] 每一步均可独立通过构建、类型检查与测试
- [ ] 替换完成后旧实现、旧兼容分支与死代码已删净（`FE-005`）
