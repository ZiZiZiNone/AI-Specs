# 接口契约

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析。见 `<SPEC_ROOT>/README.md`「路径基准」。

前后端共用的 HTTP 契约只收录于本文件。本文件只收与语言无关的结论，各语言落地形态见各子树，不重复本文件。

## 路径与方法

复数名词、无动词路径。动词由 HTTP 方法表达，路径只表达资源。

- 集合用复数：`GET /orders`、`POST /orders`；单体用 `GET /orders/{id}`、`PUT /orders/{id}`、`DELETE /orders/{id}`。
- 禁止动词路径：`POST /createOrder`、`GET /getUserById` 一律改写为资源加方法。
- 子资源用嵌套复数：`GET /orders/{id}/items`、`POST /orders/{id}/items`。
- 查询、过滤、排序走查询参数：`GET /orders?status=paid&sort=-createdAt`，不另建路径。
- 方法语义固定：查询用 `GET`，新建用 `POST`，全量替换用 `PUT`，部分更新用 `PATCH`，删除用 `DELETE`。
- 新增字段先过消费者判据，见 `common/protocol/task-boundary.md`「哪一段可达的代码、数据、接口、验收条件会消费它」：指不出消费点的不加。

## 响应信封

成功与失败同形，调用方只按一种形状解析。

- 成功：`{"code":0,"message":"ok","data":{},"requestId":"..."}`。
- 失败：`{"code":数字业务码,"message":"面向调用方的可读说明","data":null,"requestId":"..."}`。
- requestId 写入响应体必填。每一次响应体都带 `requestId`，由服务端生成，透传全链路。
- 响应头写入按各子树日志约定，不强制全局头名。各语言是否回写 `X-Request-Id`、大小写与覆盖策略，以各语言子树日志约定为准，本文件不强制全局头名。
- `message` 只给人读，机器分支只看 `code` 与 HTTP 状态码。
- `data` 无内容时用 `null` 或空对象，不省略字段，不改变信封层级。

## 业务错误码

HTTP 状态码表达传输层结果，业务码表达领域结果，两者不互相替代。

- `code==0` 为成功，非零为失败。HTTP 200 只表示送达，不表示业务成功。
- 码段按域划分，具体数值由业务项目定义，本文件只定划分方式。
- 参数错误用 `400` 加参数码，认证缺失用 `401`，权限不足用 `403`，资源不存在用 `404`，服务端故障用 `500`。
- 同一失败原因前后端共用同一业务码，不为同一语义造第二套码。
- 错误说明必须可执行：发生了什么加如何解决，不输出堆栈与内部表名。

## 分页

分页载荷为 items + page。列表接口统一形状，不允许裸数组。

- 形状：`{"code":0,"message":"ok","data":{"items":[],"page":{"page":1,"pageSize":20,"total":128,"totalPages":7}},"requestId":"..."}`。
- `page` 从 1 起计，`pageSize` 由服务端截断上限，超限返回截断后的实际值。
- `total` 为过滤后的总数，`totalPages` 可由服务端计算后返回，调用方不自行推导。
- 空页返回 `items:[]` 加正确的 `page`，不用 404 表示空结果。
- 需要保持筛选与分页可分享时，查询条件回写 URL，见各端路由约定。

## 幂等与重试

- `GET`、`PUT`、`DELETE` 默认可重试，超时或网络抖动可按退避重试。
- 非幂等请求默认不重试。`POST` 禁自动重试，临时故障也只允许人工确认后重发。
- 需防重放的 `POST` 使用幂等键：调用方生成 `Idempotency-Key`，服务端按键去重，去重窗口由业务项目声明。
- 同一幂等键重复提交返回首次结果，不执行第二次副作用。
- 重试必须带退避与上限，取消信号到达时立即中断。
- 前端落点见 `frontend/rules/async-operations.md`「幂等性前置判断」：重试的前提是重复执行不产生额外后果。

## 版本化

- 路径前缀版本：`/v1/orders`、`/v2/orders`。破坏性变更升版本，非破坏性变更不升版本。
- 存量版本只修严重缺陷，不追加字段语义变更。新增字段用可选字段加默认值兼容。
- 下线版本先标记废弃并给出替代版本与迁移期限，到期后下线。
- 废弃声明写入接口文档与响应说明，不依赖口头通知。

## 自检

- [ ] 路径为复数名词、无动词路径，方法语义正确
