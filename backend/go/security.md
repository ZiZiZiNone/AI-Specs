# Go 安全

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `common/principles.md`「逻辑解耦原则」：「后端不得依赖 `*ghttp.Request`、Laravel 的 `Request` / `Response`」与「模块解耦原则」。错误说明见 `common/rules/api-contract.md`「业务错误码」：「错误说明必须可执行：发生了什么加如何解决，不输出堆栈与内部表名」。

## 规则

- 所有外部输入在入口处校验类型、长度与取值范围，校验规则集中在逻辑单元，不分散在各入口。
- 身份与权限判定在服务层统一执行，入口只透传身份上下文，不在入口拼装权限结论。
- 敏感数据最小化输出，日志、错误说明与响应均脱敏，不输出堆栈、内部表名与密钥。
- 密钥与令牌只走密钥载体与短期有效凭证，不硬编码、不入库明文，缺失时显式失败。
- 数据访问全部参数化，数据层之外无拼接查询字符串，上传文件校验类型、大小与存放边界。
- 安全修复不扩大范围，未授权的加固动作先报告，授权面拿不准时按只读处理。

## 检查清单

- [ ] 外部输入均有集中校验
- [ ] 权限判定收敛在服务层
- [ ] 日志与响应均已脱敏
- [ ] 密钥无硬编码无明文落盘
- [ ] 无拼接查询与越界文件写
- [ ] 越界动作已先报告待授权
