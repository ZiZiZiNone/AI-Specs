# GoFrame 配置差异

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「现有子目录」与 `common/principles.md`「模块解耦原则」。

## 规则

- 只写框架差异：框架配置读取收敛在启动装配期，逻辑单元只收解析后的结构体，不直调全局配置访问点。
- 配置分层明确默认、环境覆盖与密钥载体三层，优先级与来源逐项声明，不依赖隐式覆盖。
- 新增配置项先指明直接消费者，无消费者不加。
- 敏感配置缺失即启动失败，不用空值继续运行，生产密钥只走环境与密钥载体。
- 数值型配置注明单位与取值范围，非法值启动期拦截，错误信息给出合法区间。
- 框架默认配置不直接复用为业务默认值，业务侧显式声明所需项，升级框架先核对差异。

## 检查清单

- [ ] 逻辑单元只收配置结构体
- [ ] 三层来源与优先级清晰
- [ ] 新增配置均有消费者
- [ ] 敏感缺失启动即失败
- [ ] 非法值启动期拦截
- [ ] 未隐式复用框架默认
