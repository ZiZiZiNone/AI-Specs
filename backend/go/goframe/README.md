# GoFrame 二级目录总览

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「分层原则（PHP / Go 共用）」与「现有子目录」。选型态度见 `backend/README.md`「不套用其他技术栈的规则」。

## 规则

- 本目录只写框架真正引入差异的主题，语言通用结论保留在上级目录，不重复搬运。
- 阅读顺序为上级语言文件优先，遇框架差异点再进入本目录对应文件，无对应文件即无差异。
- 控制器只做参数绑定、调服务接口、写响应，业务规则下沉服务。
- 服务为接口、逻辑为实现并依赖数据接口，依赖方向唯一且向下。
- 新增框架用法先指明直接消费者，无消费者不引入。
- 不套用其他技术栈的写法，框架升级先核对本目录差异文件，再决定是否调整上层结论。
