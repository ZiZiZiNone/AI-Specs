# PHP 代码风格

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「分层原则（PHP / Go 共用）」与 `common/principles.md`「逻辑解耦原则」。

## 规则

- 遵循统一风格并用自动化工具强制检查，未通过不合并。
- 严格类型全开，服务与仓储公开方法必须写参数与返回类型。
- 控制器方法保持薄入口，服务公开方法单一业务目标，超长即拆分私有方法。
- 数组与 DTO 优先具名构造，禁止魔术字符串，多处复用即提常量或枚举。
- 查询链式每步换行，用条件构造代替分支包裹查询；禁止字符串拼接 SQL 与插值，一律参数绑定，循环内查询另行批量化。
- 异常信息面向运维，用户文案只在资源与语言文件出现，不在逻辑层硬编码。
- 不在逻辑层直取环境与配置门面，配置经构造注入值对象。
