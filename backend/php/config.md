# PHP 配置管理

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `common/principles.md`「模块解耦原则」。

## 规则

- 配置只来自环境变量与配置文件，禁止在类中硬编码地址密钥。
- 服务与仓储所需阈值、开关经构造参数传入，不直调配置门面。
- 配置项集中定义默认值与类型，缺失必填项在启动时失败。
- 敏感配置只走环境与密钥管理，不进仓不进日志。
- 按环境拆分配置，生产配置禁止调试开关与详细错误。
- 配置变更视为发布，需经评审与冒烟验证。

## 检查清单

- [ ] 无硬编码密钥地址
- [ ] 逻辑层不直读配置
- [ ] 必填缺失启动失败
- [ ] 敏感项未进仓
- [ ] 生产无调试开关
- [ ] 变更经过评审
