# PHP 安全规范

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「分层原则（PHP / Go 共用）」。

## 规则

- 入口统一校验参数白名单，服务假定输入已整形并复核业务权限。
- 全部查询用参数绑定，禁止字符串拼接查询与原生语句插值。
- 输出统一编码，错误体不回显内部实现细节。
- 密码用专用哈希校验，令牌存哈希，敏感字段落库加密。
- 权限在服务方法级校验，禁止仅靠路由隐藏敏感操作。
- 上传校验类型大小与内容，存储隔离执行，不可直接执行。
- 高风险写操作记审计日志，含操作者、对象与脱敏后前后值；口令、令牌与个人敏感信息只记哈希或掩码，键名全仓统一。

## 检查清单

- [ ] 参数白名单齐备
- [ ] 无拼接查询
- [ ] 对外无敏感泄露
- [ ] 口令令牌存储合规
- [ ] 方法级权限已覆盖
- [ ] 上传隔离已验证
- [ ] 审计可追溯
