# PHP 日志记录

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「分层原则（PHP / Go 共用）」。

## 规则

- 经标准日志接口构造函数注入记录，禁止门面直调。
- 服务记录业务关键转折，仓储只在慢查询与约束冲突时记调试日志。
- 日志上下文用结构化数组，含聚合标识与操作结果；口令、令牌与个人敏感信息默认不记，确需记则字段白名单加脱敏。
- 级别严格区分：业务失败用告警级别，系统异常用错误级别，流程追踪用信息级别。
- 单次请求统一请求标识贯穿各层，由控制器生成并向下传递。
- 生产环境用结构化单行，本地可用可读格式，格式由配置决定不写死。

## 检查清单

- [ ] 日志器经注入传入
- [ ] 无门面直调日志
- [ ] 上下文结构化且脱敏
- [ ] 级别使用正确
- [ ] 请求链路可串联
- [ ] 敏感字段未落盘
