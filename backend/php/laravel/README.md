# Laravel 框架规范入口

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「现有子目录」。

## 规则

- 仅框架项目加载本目录，纯语言包不加载。
- 上层已有结论不重复，差异点用路径加摘录回链到上层。
- 门面、数据模型事件、请求生命周期差异必须落到本目录对应主题。
- 差异描述具体到版本行为，禁止空话。
- 新增框架主题先证明上层无法覆盖，否则不建文件。
- 框架升级先更新本目录，再改业务代码。

- [ ] 差异具体可执行

- [ ] 升级顺序正确
