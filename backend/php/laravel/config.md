# Laravel 配置差异

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「现有子目录」与 `common/principles.md`「模块解耦原则」。

## 规则

- 业务配置收敛到专属文件，经配置缓存验证，不散写服务类。
- 逻辑层不直调配置门面与环境助手，所需值由提供者注入。
- 敏感键只读环境，示例文件只留空键，真实值不进仓。
- 配置变更后重建缓存并冒烟覆盖关键路径。
- 按环境覆盖文件最小化差异，生产禁用调试与详细错误。
- 第三方服务超时重试等阈值纳入配置，不硬编码。

## 检查清单

- [ ] 配置文件收敛
- [ ] 逻辑层无直读
- [ ] 敏感未进仓
- [ ] 缓存冒烟已覆盖
- [ ] 生产无调试
- [ ] 阈值可配置
