# Laravel 日志差异

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「分层原则（PHP / Go 共用）」。

## 规则

- 经服务容器注入标准日志接口，禁止在服务直调日志门面。
- 用框架通道区分运行、审计、队列，配置集中不在代码散写。
- 请求关联标识由中间件生成并经参数透传，不在日志层读请求门面。
- 队列任务日志带任务标识与重试次数，便于串联排查。
- 本地用可读栈，生产用结构化单行，字段命名统一。
- 敏感上下文在写入前脱敏，上下文键名全仓统一。
