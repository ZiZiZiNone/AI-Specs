# Laravel 分层落点

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析，首段为 `common/`、`frontend/` 或 `backend/`。见 `<SPEC_ROOT>/README.md`「路径基准」。

基准见 `backend/README.md`「分层原则（PHP / Go 共用）」与 `common/principles.md`「薄入口原则」。

## 规则

- 控制器方法只做表单请求校验、调服务、返资源，行数从严控制。
- 服务经构造注入仓储接口，不用门面解析。
- 仓储封装全部查询实现，服务禁止直调模型查询构造器。
- 表单请求只做格式校验，业务存在性与权限校验归服务。
- 资源类只做字段映射，不做业务计算与条件分支。
- 路由模型绑定结果先转纯数据再进服务，不传模型绑定的请求上下文。

## 检查清单

- [ ] 入口无业务判断
- [ ] 服务经构造注入
- [ ] 查询收敛仓储
- [ ] 表单请求无业务规则
- [ ] 资源类无计算
- [ ] 绑定结果已转纯数据
