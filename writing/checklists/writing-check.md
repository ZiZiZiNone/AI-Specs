# 写作交付前自检清单（`writing/checklists/writing-check.md`）

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析。见 `<SPEC_ROOT>/README.md`「路径基准」。

每次完成写作交付前，先过「通用底线」，再只勾选本次命中的 **1 个场景区块**。

## 通用底线自检（所有场景必过）

- [ ] 已对齐目标受众、写作目的、阅读载体与字数/格式约束（`writing/rules/core.md`）
<!-- writing-check: ignore -->
- [ ] 已清除 AI 味高频套话（总而言之、综上所述、值得注意的是、赋能、抓手、闭环、机械三段排比等）
- [ ] 事实、数字、案例与引用全部有据可查，零编造（`COM-014`）
- [ ] 语言简明直白，长短句交替，移动端/网页可快速扫读
- [ ] 已通过 `scripts/check-writing.py` 校验（若写入磁盘或经 Hooks 自动执行）

## 场景专属自检（按需只过 1 项）

### 报告与方案（`writing/rules/report.md`）
- [ ] 首句即明确结论或推荐方案，非过程流水账
- [ ] 论据分组符合 MECE，小标题为结论句而非空标签
- [ ] 包含备选方案对比、否决理由、主要风险与下一步行动表

### 文章与深度内容（`writing/rules/article.md`）
- [ ] 资讯类首段交代核心事实；深度类前几段内给出核心导语（Nut Graf）
- [ ] 标题承诺与正文兑现一致，单篇只打透 1 个核心主题
- [ ] 段落轻量化（2–4 句），小标题携带核心信息

### 宣传稿与营销文案（`writing/rules/copywriting.md`）
- [ ] 已匹配受众认知阶段（AIDA / PAS / FAB / BAB 选型正确）
- [ ] 所有产品特性均已转译为“用户能得到的具体收益”，并附具体证据
- [ ] 结尾仅推 1 个清晰、低门槛的核心行动指引（CTA）

### 网文连载与全类型小说（`writing/rules/web-novel.md`）
- [ ] **实感锚定**：每场戏含 2–3 个具体感官/生活细节，无空洞宏大辞藻
- [ ] **贴身视角**：已删净“他心想/他感到/他意识到”过滤词，无随意跳头
- [ ] **句长突发度**：铺垫长句与冲突极短断句交替明显，无节拍器式均匀句长
- [ ] **规则与代价**：金手指/优势有明确限制或代价，无降智反派送人头
- [ ] **连载钩子与零陈词**：本章有明确局势推进，章末钩子不与上章撞车，零网文/AI 烂梗词

### 说明与操作文档（`writing/rules/documentation.md`）
- [ ] 严格归属 Diátaxis 单一象限（教程 / 指南 / 参考 / 原理），无混写
- [ ] 操作步骤用祈使句动词起手，一步一动作，关键步骤附可见验收结果
- [ ] 不可逆风险提示写在步骤之前，全文术语名称 100% 统一

### 职场沟通与函件（`writing/rules/correspondence.md`）
- [ ] 主题行含动作与截止时间，正文首段直接亮明目的与请求
- [ ] 待办事项写清“负责人 + 动作 + 精确日期时间”，无模糊“尽快”
- [ ] 无公文官腔与双重否定，跨部门/对外沟通已转译内部黑话
