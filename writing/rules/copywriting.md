# 场景三：宣传稿与营销文案写作规范（`writing/rules/copywriting.md`）

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析。见 `<SPEC_ROOT>/README.md`「路径基准」。

适用范围：产品发布稿、活动推广、品牌软文、社交媒体种草、落地页/详情页文案、转化邮件。
理论底座：Eugene Schwartz 受众五阶认知模型 + AIDA / PAS / FAB / BAB 转化框架 + Unbounce 4.64 亿访客可读性基准 + Cialdini 说服心理学。

## 第一步：先定受众认知阶段，再选文案模型

严禁不看受众直接套模板。先判断目标读者处于哪个认知阶段，再匹配对应框架：

| 受众认知阶段 | 读者心理状态 | 首选文案框架 | 开头核心打法 |
|---|---|---|---|
| **无认知 / 泛流量（冷受众）** | 没意识到自己有问题，更没听过你 | **AIDA**（注意→兴趣→渴望→行动） | 用反常识事实、生活场景或强共鸣痛点抓注意力，先不提产品名 |
| **痛点认知（温受众）** | 知道自己很难受，但以为没好办法 | **PAS**（痛点→放大代价→给解法） | 用读者自己的原话精准说出痛点，算清拖延的真实代价，再引出解法 |
| **方案对比（热受众）** | 知道有多种解法，正在货比三家 | **FAB**（特性→优势→具体收益） | 不堆参数，把每个卖点翻译成“所以你能省下/赚到/避开什么” |
| **案例信任 / 临门一脚** | 认识你的产品，只差信任与临门推力 | **BAB**（改变前→改变后→桥梁） | 用真实前后对比、具体数据与零风险承诺打消最后顾虑 |

## 四条高转化硬规则

1. **大白话胜过专业腔（亿级转化实证）**
   - Unbounce 4.64 亿访客基准证实：通俗易读文案的转化率是晦涩专业腔的 2 倍以上。
   - 删掉“赋能、极致、颠覆、行业领先、全维升级”等自嗨形容词；每个特性都必须经过 **“所以你能……”测试**（例：不写“搭载低功耗芯片”，写“充一次电稳用 7 天，出差不用带充电器”）。
2. **用“具体证据”替代“空口承诺”**
   - 善用真实数字、使用场景、第三方评价、对比实验与风险兜底（如试用、退换、保障条件）建立信任；严禁捏造虚假销量、虚假好评或夸大疗效/收益。
3. **单一页面 / 单条文案只推一个核心动作（1:1 注意力原则）**
   - 每篇宣传文案结尾必须有**清晰、低门槛、唯一的行动指引（CTA）**（如“立即免费试用 7 天”“点击预约直播”），避免同时塞进 3–4 个互相抢注意力的跳转指令。
4. **公关新闻稿特殊要求**
   - 若为对外媒体通稿/新闻发布稿，改用**客观第三人称 + 倒金字塔**（首段交代发布主体、核心事件、时间与行业意义，中段配高管克制引语与关键数据，末尾附公司简介），避免广告叫卖腔。

## 禁止事项

- 禁止对冷流量一上来就抛折扣码或生硬背参数。
- 禁止堆砌空洞最高级词汇（最、第一、绝对、史无前例、颠覆全行业）而无实证支撑。
- 禁止只讲“我们公司有多牛”，全文不提“读者能得到什么改变”。
