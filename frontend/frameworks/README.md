# frontend/frameworks

路径基准：本文所有裸路径相对规范库根 `<SPEC_ROOT>` 解析。见 `<SPEC_ROOT>/README.md`「路径基准」。

本目录覆盖三大主流前端技术栈，均配有零依赖可运行参考切片与 `tsconfig.json`：

- `frontend/frameworks/vue3/`：Vue 3.5 + Pinia + Vue Router + Arco Design（可运行切片：`frontend/frameworks/vue3/test/`）
- `frontend/frameworks/react/`：React 19 + Next.js App Router + Server Actions（可运行切片：`frontend/frameworks/react/test/`）
- `frontend/frameworks/miniprogram/`：微信小程序原生 TS + TDesign / Vant Weapp（可运行切片：`frontend/frameworks/miniprogram/test/`）
